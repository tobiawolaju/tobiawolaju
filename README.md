## About

I build across software, real-time systems, blockchain, AI, and physical computing, from browser-based multiplayer infrastructure and on-chain systems to embedded electronics and telecom research.

I'm drawn to difficult engineering problems, especially where software meets physical systems. I learn by building, testing, and iterating.
