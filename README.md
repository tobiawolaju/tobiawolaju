### EEG Communication Headset
*Embedded systems · Signal acquisition · Assistive technology*

An experimental wearable communication-support interface exploring how EEG signals can support intentional input for people who cannot communicate conventionally.

**What I'm building**
- EEG acquisition using TGAM modules.
- ESP32-based embedded firmware.
- Signal processing and input interpretation.
- Audio output through bone-conduction speakers.

The research focuses on identifying useful communication-related signals, not arbitrary thought decoding.

**Technology:** ESP32 · Embedded C/C++ · EEG · UART · Digital signal processing

### Cellular Fingerprint Positioning
*Telecommunications · RF systems · Signal processing*

My final-year Electrical Engineering project, exploring position estimation using cellular signal measurements and cell information in environments where satellite positioning is unreliable or unavailable.

**Focus areas**
- Cellular signal measurements.
- Radio-frequency propagation.
- Signal processing and positioning.
- Localization using cellular network information.

**Technology:** Telecommunications · RF systems · DSP · Cellular networks
